关于我

我习惯把混乱的事情理出流程。本科四年当班长，最常做的事就是把一届人的通知、评奖、答辩组织得明明白白；写代码时也是同一套思路——先拆流程，再写自动化。

硕士期间我独立做了一个「人才检索本地工作台」：招聘同学原本要在脉脉、BOSS 直聘、猎聘几个网站之间反复搜同一组关键词、再手工把候选人贴回 Excel。我把整条链路做成了一个双击启动、浏览器里操作的本地工具，让不写代码的同事也能开箱即用。

目前方向：城市韧性与企业组织内智能优化协作——一边做极端高温等城市灾害下的应急资源调度优化，一边用 Agent 工具把组织内重复的协作流程自动化。

03 / PROJECT

代表项目 · 硕士期间独立完成

PROJECT · 招聘团队内部工具

人才检索本地工作台

一套面向招聘团队的本地自动化工作台：把「录岗位 → 筛简历 → 多平台捞人 → 统一导出 Excel」整条链路，收敛到一个浏览器页面里完成。后端是 Python 本地服务，前端是单页 Web 界面，底层桥接大模型 Agent 自动驱动浏览器完成脉脉、BOSS 直聘、猎聘的检索动作。双击启动、解压即用，只监听本机、不对外网暴露。

AI · 读文件 / 分析

AI 在本地读简历、读 JD、做判断

不打开任何网站，纯文本推理：自动拆 JD 文件、批量匹配简历、按岗位打分分类。结果直接落 Excel。

配套 Skill：简历筛选、岗位生成都有独立 Skill 文档，规定输出字段、评分维度和判断规则，AI 按 Skill 执行而不是自由发挥。

AI · 自动打开浏览器点击

AI 亲自上脉脉 / BOSS / 猎聘 / 学术网站

不抓后台接口，AI 像人一样慢速滚动、点卡片、读页面内容，再把候选人公开资料结构化导出。

配套 Skill：脉脉关键词、脉脉 Excel、BOSS、猎聘、论文作者、目标实验室各有独立 Skill，规定搜索语法、滚动节奏和反风控策略。

01

岗位生成 / 录入

AI 分析
两条路径：A 是手动录入或上传 JD 文件（Excel / Word / PDF / TXT / Markdown / RTF），AI 自动识别其中的一个或多个岗位并结构化入库；B 是只填岗位名称和加分 / 排除方向，AI 反向生成可编辑的岗位介绍，满意后一键导出 JD Word 版。

03

简历自动匹配岗位

AI 分析
批量上传技术岗简历，AI 自动读取所有「开放中」的岗位，对每份简历做最佳匹配，输出最佳匹配岗位、匹配分数、匹配理由、其他可能岗位。超过 3 份自动拆成每批 3 份的串行任务。
▲ 03 简历自动匹配（上）/ 04 按岗位批量筛选（下）
04

按岗位批量筛选简历

AI 分析
从岗位库选一个开放岗位（或手动填方向），批量上传简历做定向筛选。AI 按岗位完整 JD 输出推荐 / 待定 / 不推荐三档，附带岗位适配性评分，最终导出 Excel + Markdown 报告。
05

脉脉 Excel 检索更新

AI 操作浏览器
上传已有候选人 Excel，AI 自动打开脉脉、按姓名列逐个反查，补全年龄、地点、脉脉个人页链接。多个 Excel 严格串行、不并行，避免同一浏览器账号被多任务同时驱动。
06

脉脉关键词检索

AI 操作浏览器
用 DSL 风格语法描述搜索范围，例如「字节跳动 / 飞书｜商业化 / 销售 / 企业服务｜总经理 / 负责人 / VP / 总监」，AI 在脉脉上自动拆成可验收的串行检索计划，按动态停止条件执行，全部单元完成后统一去重导出 Excel。
07

BOSS 直聘关键词搜索

AI 操作浏览器
AI 在 BOSS 推荐牛人页面慢速读取卡片（不抓后台接口），按筛选规则（如「阿里 / 通义 / 算法；华为 / 盘古 / 算法」）筛人，可选收藏命中者，最后导出 Excel。刻意慢速滚动是为了不触发风控。
08

猎聘关键词搜索

AI 操作浏览器
按关键词（如「字节 销售总经理」）+ 资格规则 + 目标人数，AI 自动打开猎聘检索候选人。每次只跑一个关键词、不并行、安全限流。

关键技术设计

双执行引擎热切换

Codex CLI 与 SenseAudio S2 共用同一套子进程调用逻辑，通过隔离目录切换，不污染本机登录态；密钥只写本机配置文件。

按模块分 lane 的调度器

默认 5 并发；共用同一浏览器登录态的脉脉 / BOSS / 猎聘任务被约束在同一 lane 互斥执行，避免同一账号被多任务同时驱动。

任务状态机与断点恢复

7 种任务状态；服务重启时扫描结果目录自动恢复任务列表，刷新页面不丢任何进度。

流式实时推理弹窗

任务执行时右下角浮动窗流式渲染 Agent 的每一步，下一个任务自动切换。

任务级人工介入

每个任务卡片下可随时发指令：「已登录，继续」「验证码处理好了」「只保留自研论文」，把 Agent 卡壳时的人工兜底做成一等公民。

Skill 自进化闭环

任务完成后提交一句评价，Agent 自动根据执行日志修改对应 Skill 文档，让工具在真实任务中持续迭代。
